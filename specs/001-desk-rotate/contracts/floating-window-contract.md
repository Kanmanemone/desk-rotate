# UI Contract: 데스크톱별 플로팅 창

**Feature**: `001-desk-rotate` | 관련 요구사항: FR-004~FR-010, FR-015, FR-021, spec.md User Story 1~4 Edge Cases

데스크톱마다 하나씩 존재하는 플로팅 창의 표시 내용과 상호작용 계약.

## 표시 내용 (모든 창에서 동일)

| 항목 | 갱신 시점 | 관련 요구사항 |
|---|---|---|
| 다음 자동 전환까지 남은 시간 | 매초 갱신, 전환 발생 시 리셋 | FR-005 |
| 프로그램 종료까지 남은 전체 시간 | 매초 갱신 | FR-005, FR-014 |
| 데스크톱별 누적 전환 횟수 (전체 목록) | 검증된 전환이 반영될 때마다 갱신 | FR-006 |
| 목표 도달 여부 | `TargetReached == true`가 되면 "완료" 상태로 전환 표시가 멈췄음을 나타냄 | FR-015 |

## 초기 배치

- 창이 처음 생성될 때 화면 상단 중앙(12시 방향)에 나타난다 (FR-021).
- 이후 사용자가 자유롭게 드래그해 옮길 수 있다. 옮긴 위치는 세션 동안만 유지되며 앱 재시작 시 다시 상단 중앙으로 초기화된다.

## 닫기 상호작용

1. 사용자가 창을 닫으려 시도(X 버튼 등) → "정말 종료할까요?" 확인 다이얼로그를 띄운다 (FR-008). 이 사이에도 `RotationSession`은 계속 갱신된다.
2. 사용자가 **취소** → 다이얼로그를 닫고 창은 그대로 유지, 아무 것도 종료되지 않는다 (FR-010).
3. 사용자가 **종료 확정** → 프로그램 전체(모든 데스크톱의 창, 회전, 검증 로직 포함)를 종료한다 (FR-009). 개별 창 하나만 닫는 동작은 없다 — 종료는 항상 전체 종료다.

## 항상-위 표시

- 모든 플로팅 창은 always-on-top으로 유지된다. 정확한 스타일(투명도, 클릭 통과 여부 등)은 구현 재량이다.
