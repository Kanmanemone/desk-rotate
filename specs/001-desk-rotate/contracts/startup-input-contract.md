# UI Contract: 시작 입력 폼

**Feature**: `001-desk-rotate` | 관련 요구사항: FR-003, FR-011, FR-013, FR-014, FR-026, FR-027, FR-036, FR-037, FR-038, FR-039, spec.md Edge Cases

앱 실행 시 사용자가 처음 마주치는 입력 화면의 계약. 순수 로직(입력 검증, 총 예상 실행 시간 계산)은 이 계약을 기준으로 단위 테스트한다.

## 입력 필드

| 필드 | 타입 | 필수 | 기본값 | 검증 규칙 | 실패 시 동작 |
|---|---|---|---|---|---|
| 순회 시작 데스크톱 번호 | 정수 | 예 | 1 | 1 이상 | 시작 거부, 재입력 요구 (FR-003) |
| 순회 끝 데스크톱 번호 | 정수 | 예 | 3 | 1 이상, 시작 번호 이상 | 시작 거부, 재입력 요구 (FR-027, Edge Cases) |
| 전환 간격 | 정수(초/분 등 UI 재량 단위) | 예 | 300초(5분) | 1 이상 | 시작 거부, 재입력 요구 |
| 목표 사이클 수 | 정수 | 예 | 4 | 1 이상 | 시작 거부, 재입력 요구 (FR-013, Edge Cases: "0 이하 입력 거부") |
| 초 단위 표시 | 온/오프 | 예 | 켜짐 | — | 해당 없음 (FR-031) |
| 사이클 번호 표시 | 온/오프 | 예 | 켜짐 | — | 해당 없음 (FR-031) |
| 진행률 원 표시 | 온/오프 | 예 | 켜짐 | — | 해당 없음 (FR-036) |

기본값은 FR-026에 따라 폼이 열릴 때 미리 채워져 있어야 한다(사용자가 아무것도 바꾸지 않고 바로 시작할 수 있도록).

표시 옵션 체크박스 3개는 고정 픽셀 폭이 아니라 실제 렌더링 시점의 글꼴·DPI 배율 기준으로 스스로 크기를 계산해야 한다(FR-037) — 특정 환경에서 측정한 고정 폭은 다른 DPI 배율에서 텍스트가 잘려 보일 수 있다.

## 화면 구획 — 입력부 / 확인부 (FR-038)

이 폼은 하나의 얇은 수평 구분선으로만 나뉘는 두 구획으로 구성된다(별도의 테두리 상자·제목 등 거창한 시각적 구획은 두지 않는다):

- **입력부**: 순회 범위, 전환 간격, 목표 사이클 수, 표시 옵션 체크박스 3개, 오류 메시지.
- **확인부**: 총 예상 실행 시간(아래 파생 표시값), 시작 전 대기 시간 안내(아래), "시작" 버튼.

## 파생 표시값

- **목표 총 전환 횟수** = 목표 사이클 수 × 순회 대상 데스크톱 개수 (FR-013). 시작 입력 폼에는 별도로 표시할 필요는 없지만, 총 예상 실행 시간 계산에 쓰인다.
- **총 예상 실행 시간** = 전환 간격 × 목표 총 전환 횟수 (FR-014). 유효한 입력이 모두 채워지면 실시간으로 갱신되어 미리보기로 보여준다(제출 전에도 확인 가능해야 함 — SC-005). 확인부에 위치 (FR-038).
- **순회 대상 데스크톱 개수** = 끝 번호 − 시작 번호 + 1 (파생, 화면에 별도로 표시할 필요는 없지만 `RotationSession` 생성 시 내부적으로 계산됨).
- **시작 전 대기 시간 안내** (FR-039, 확인부 위치): "시작" 버튼 근처에, 실제 데스크톱 1번을 찾는 데 걸리는 고정 시간(정확한 초 단위 — `RotationEngine.GuaranteedFirstDesktopSeekSeconds`)과, 그 이후 범위를 준비하는 동안 추가로 걸릴 수 있는 시간(정성적 안내만)을 함께 보여준다. 입력값과 무관하게 항상 같은 문구다(범위·간격·사이클 수에 좌우되지 않음).

## 제출 시 동작

1. 모든 필드가 유효하면(끝 ≥ 시작 포함): `RotationSession` 생성 → 초기 탐색(FR-022, 범위 시작까지 이동 — 매 단계 실제 전환 여부 확인 후 필요시 새 데스크톱 생성, FR-033) → 초기 설정 과정(FR-020, 범위 안 데스크톱 자동 순회 및 창 배치 — 마찬가지로 FR-033 적용) → 완료 후 평소 회전 시작.
2. 하나라도 유효하지 않으면: 제출을 막고 해당 필드에 오류를 표시한다. 다른 필드 값은 유지한다(사용자가 처음부터 다시 입력하지 않도록).

## 출력(비상호작용)

- 이 화면은 결과를 반환하지 않고, 성공 시 `RotationSession` 시작으로 이어진다. 실패 시 화면에 남아 재입력을 기다린다.
