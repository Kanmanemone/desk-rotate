# desk-rotate

정해진 간격마다 Windows 가상 데스크톱을 지정한 범위 안에서 자동으로 순환 전환해주는 개인용 Windows 유틸리티. 포모도로식으로 여러 작업 맥락(가상 데스크톱)을 강제로 오가며 순환시키는 것이 목적이며, 각 데스크톱에는 남은 시간과 통계를 보여주는 작은 플로팅 창이 함께 뜬다.

## 주요 기능

- **범위 기반 순회**: 데스크톱 개수가 아니라 범위(예: 시작 3 ~ 끝 7)를 입력받아, 그 범위 안의 데스크톱만 균일하게 순환 전환한다. 범위 끝에 도달하면 시작으로 되돌아간다(핑퐁이 아닌 순환 방식).
- **사이클 단위 목표**: 목표 횟수 대신 목표 **사이클 수**를 입력받는다. 1 사이클 = 범위 안 데스크톱을 한 번씩 모두 도는 것.
- **공식 API 기반 전환 검증**: `SendInput`으로 `Ctrl+Win+←/→` 키 입력을 시뮬레이션해 전환하고, 공식 `IVirtualDesktopManager.IsWindowOnCurrentVirtualDesktop`으로 실제 도달 여부를 검증한다. 실패하면 재시도하고, 그래도 안 되면 실제 위치로 내부 상태를 자가 보정한다. 이 프로그램은 비공식·비문서화 COM 인터페이스나 `SetForegroundWindow` 같은 강제 포커스 트릭을 쓰지 않는다.
- **존재하지 않는 데스크톱 자동 생성**: 입력한 범위의 데스크톱이 아직 존재하지 않으면, Windows 표준 "새 데스크톱 추가" 단축키(`Win+Ctrl+D`)로 자동 생성한다. 이미 있는 데스크톱은 최대한 재사용한다.
- **최소/상세 두 단계 플로팅 창**: 평소에는 테두리 없이 남은 시간 숫자만 표시(최소 보기)하고, 클릭하면 총 예상 실행 시간·종료까지 남은 시간·데스크톱별 전환 횟수를 보여주는 상세 보기로 전환된다. 상세 보기에는 커스텀 닫기(×) 버튼과 일시정지/재개 버튼이 있다.
- **일시정지/재개**: 상세 보기의 버튼으로 언제든 카운트다운과 자동 전환을 멈췄다가 이어갈 수 있다. 세션은 하나뿐이라 어느 데스크톱의 창에서 눌러도 모든 창에 즉시 반영된다.
- **드래그 이동 + 테두리 자석 스냅**: 창 본문을 드래그해 원하는 위치로 옮길 수 있고, 화면 테두리 가까이 가져가면 살짝 달라붙는다.
- **실수 방지 종료 절차**: 플로팅 창을 닫으려 하면 "정말 종료할까요?" 확인을 거치며, 확정해야만 프로그램 전체(모든 데스크톱의 창 포함)가 종료된다.

## 요구 사항

- Windows 10 (버전 1903/빌드 18362 이상) 또는 Windows 11
- .NET 8 SDK (빌드 시) / .NET 8 데스크톱 런타임 (실행만 할 경우)

## 실행 방법

1. 저장소를 zip으로 내려받아 압축을 푼다.
2. `DeskRotate.bat`을 더블클릭한다.
   - .NET 8 SDK가 없으면 설치할지 물어본다. 동의하면 관리자 권한 없이 이 폴더 안에만 설치된다(시스템 전역 설치 아님).
   - 이어 프로그램이 자동으로 빌드되고 **저장소 루트에 `DeskRotate.lnk` 바로가기가 새로 만들어진 뒤**, 앱이 실행된다.
3. 다음부터는 `DeskRotate.bat` 말고 방금 만들어진 **`DeskRotate.lnk`를 더블클릭**하면 바로 실행된다.

`.lnk`는 만든 컴퓨터의 절대경로를 저장하는 파일이라 저장소에 미리 넣어 둘 수 없다 — 그래서 완성된 `.lnk`를 커밋해 두는 대신, `DeskRotate.bat`이 실행될 때마다 그 컴퓨터 기준으로 새로 만든다.

## 사용법

1. 앱을 실행하면 시작 설정 창이 뜬다. 기본값은 다음과 같다.
   - 순회할 데스크톱 범위: **1 ~ 3**
   - 전환 간격: **300초(5분)**
   - 목표 사이클 수: **4**
   - 초 단위 표시 / 사이클 번호 표시: **둘 다 켜짐**
2. "시작"을 누르면 앱이 필요한 데스크톱을 자동으로 순회·생성하며 각 데스크톱에 플로팅 창을 배치한 뒤, 원래 있던 위치로 돌아와 회전을 시작한다. 이 과정에서 화면이 짧게 여러 데스크톱을 오가는 것이 보일 수 있다(정상 동작).
3. 설정한 간격마다 자동으로 다음 데스크톱으로 전환되며, 목표 사이클에 도달하면 전환은 멈추고 플로팅 창에 최종 통계가 계속 표시된다.
4. 플로팅 창을 클릭하면 최소/상세 보기가 전환되고, 드래그하면 위치를 옮길 수 있다.
5. 아무 플로팅 창이나 닫으려 하면 확인 후 프로그램 전체가 종료된다.

## 프로젝트 구조

```text
src/DeskRotate/
├── Program.cs                   진입점 — 시작 설정 창 표시 후 RotationEngine 기동
├── RotationSession.cs           세션 상태(범위, 간격, 목표 사이클, 표시 옵션 등)와 파생 계산
├── VerificationOutcome.cs       전환 검증 결과 값 객체, 재시도/자가 보정 판단 로직
├── RotationEngine.cs            타이머 기반 전환 시도·검증·재시도·초기 설정 오케스트레이션
├── VirtualDesktopInterop.cs     IVirtualDesktopManager P/Invoke·COM interop 래퍼(공식 API만)
├── KeyboardSimulator.cs         SendInput 기반 데스크톱 전환/생성 키 입력 시뮬레이션
├── StartupInputForm.cs          시작 설정 입력 폼
└── FloatingWindowForm.cs        데스크톱별 최소/상세 보기 플로팅 창(데스크톱당 1개)

tests/DeskRotate.Tests/          RotationSession·VerificationOutcome 순수 로직 단위 테스트(xUnit)
```

OS와 직접 연동하는 부분(가상 데스크톱 조회, 키 입력 시뮬레이션, 실제 창 동작)은 자동화 테스트 대신 `specs/001-desk-rotate/quickstart.md`의 수동 시나리오로 검증한다.

## 알려진 제한 사항

- 전환 타이밍은 초 단위로 정밀하지 않을 수 있다 — 검증·재시도 과정에서 몇 초의 지연이 발생할 수 있으며, 이는 의도된 동작이다(정확한 타이밍보다 안정성을 우선).
- 세션 도중 사용자가 가상 데스크톱의 순서를 바꾸거나 삭제하면 완전한 재동기화는 보장되지 않는다 — 필요하면 앱을 재시작한다.
- 전환 횟수·상태는 세션(앱 실행) 범위에서만 유지되며 재시작 시 초기화된다.
